## 4. Past winners in detail

### Edition I (Austin)

**1st: Stringer Safety** ([stringersafety.com](https://stringersafety.com))
- Captain: Anjan Sundaram, journalist (Rwanda conflict coverage).
- Built: mobile app for journalists to build trusted contact networks, share location and status securely, trigger one-click SOS alerts with encrypted AI-powered response recommendations.
- Stack: Maple (encrypted AI).
- Quote: "This makes a complex personal security problem very simple to manage with a one-button touch."

**2nd: Pathos** ([pathos.place](https://pathos.place/))
- Captain: Leopoldo Lopez, Venezuelan democratic opposition leader.
- Built: decentralized Nostr app for country-specific activist communities to report events, share globally, and earn bitcoin for contributions.
- Stack: Nostr, Breeze SDK (bitcoin wallet), Bitchat (offline messaging), private AI assistant.
- Quote: "We have a tested platform, engaged community, growth potential across countries, and excited developers."

**3rd: Corruption Disrespector** ([corruptiondisrespector.com](https://www.corruptiondisrespector.com))
- Captain: Anna Chekhovich, financial director of Alexei Navalny's Anti-Corruption Foundation.
- Built: AI extraction of people, companies, addresses, and accounts from multilingual corporate, financial, and court documents, visualized as network maps.
- Quote: "Useful for anti-corruption, journalism, human rights research, war crime documentation, and investigations."

**Later funded: Enclave** (enclave.free)
- Imagined by Berta Valle, Nicaraguan human rights defender; vibe coded at edition I.
- Secure upload of case files, rapid AI analysis, and instant answers, inside hardware secure enclaves.
- Source: [HRF search result summaries](https://hrf.org/latest/hrfs-ai-fund-supports-10-innovative-projects/).

### Edition II (Nashville)

**1st: Tarkus** ([tarkus-phi.vercel.app](https://tarkus-phi.vercel.app/))
- Captain: Jhanisse Vaca-Daza (Bolivia), strategic nonviolence trainer.
- Built: open-source, self-hostable AI platform generating educational materials, culturally relevant lessons, and case studies for in-person nonviolence workshops; live Q&A for students; an AI agent analyzing participant interactions to give trainers real-time feedback on learning gaps.
- Quote: "AI enhances the training experience while the trainer builds the trust and legitimacy to transfer the skills."
- Note: hosted on Vercel despite "self-hostable" framing (INFERRED from URL).

**2nd: Zuka** ([zuka.live](https://zuka.live/))
- Captain: Anaise Kanimba (Rwanda).
- Built: AI-generated avatars (face, voice, name, biography) so dissidents and journalists can publish videos and social content anonymously; built on Nostr with integrated bitcoin wallets.
- Quote: "Zuka was built in honor of all the brave Rwandans who have been imprisoned, disappeared and killed for speaking the truth."

**3rd: Roshan**
- Captain: Roya Mahboob (Afghanistan).
- Built: personalized AI learning companion for English exam prep, job skills, and STEM; adaptive lessons and quizzes; offline operation with preloaded materials for low-connectivity areas.
- Status at announcement: in testing, planned rollout to 2,000 female students.
- Quote: "Education should not disappear just because a classroom closes."

Also mentioned in search results: AfghanDreamers.ai, a learning companion for girls (INFERRED to be related to Roshan).

## 6. Toolchain facts

### Maple AI / Maple Proxy (VERIFIED)
- API access requires Pro, Team, or Max, from $20/month.
- Desktop app: Settings → API Management → Local Proxy → Start Proxy; default `http://localhost:8080/v1`.
- Docker: `ghcr.io/opensecretcloud/maple-proxy:latest` with `MAPLE_BACKEND_URL=https://enclave.trymaple.ai`, `MAPLE_API_KEY`, optional `MAPLE_ENABLE_CORS=true`.
- Models listed: `kimi-k2-6`, `gpt-oss-120b`, `deepseek-v4-pro`, `glm-5-1`, `llama3-3-70b`, `qwen3-vl-30b`, `gemma4-31b`. The doc's curl example uses `llama-3.3-70b`, which does not match the list; use `/v1/models`.
- Works with any OpenAI-compatible client via base URL.
- Sources: [docs](https://blog.trymaple.ai/maple-proxy-documentation/), [GitHub](https://github.com/opensecretcloud/maple-proxy).
- INFERRED: the proxy performs the encryption to the enclave, so the machine running the proxy sees plaintext.

### Nostr Wallet Connect (VERIFIED)
- Connection string format: `nostr+walletconnect://` containing wallet pubkey, relay URL, secret.
- Wallets can set per-payment max, daily and monthly budgets, and expiry.
- Coinos (2024 operator note): string lives under profile details; one admin string with full control; receive-only strings cannot send; multi-string budgets "coming soon" (current state unconfirmed).
- Alby Hub is self-custodial and must be running to process payments.
- Sources: [Nostr User Guide](https://nostrcg.github.io/userguide/using-nostr/wallet-connect/), [Stacker News](https://stacker.news/items/687799), [NWC docs](https://docs.nwc.dev/), [Alby NWC JS SDK](https://guides.getalby.com/developer-guide/nostr-wallet-connect-api/building-lightning-apps/nwc-js-sdk).

### nak, Nostr Army Knife CLI (VERIFIED)
- Install: `brew install nak`.
- `nak key generate` (hex secret), `nak key public <hex>`, pipe into `nak encode nsec` / `nak encode npub`.
- Publish: `nak event -c 'hello world' relay.damus.io`; profile: `nak event -k 0 -c '{"name":"..."}'`.
- Read: `nak req -k 1 -l 10 relay.damus.io`.
- Source: [nak README](https://github.com/fiatjaf/nak/blob/master/README.md).

### Hermes Agent, OpenClaw, OpenCode
- Hermes Agent: open-source agent by Nous Research, released February 2026, multi-channel (Telegram, Slack, Discord, WhatsApp). VERIFIED from search summary, [lablab.ai comparison](https://lablab.ai/ai-articles/hermes-agent-vs-openclaw-for-ai-hackathon).
- OpenClaw: open-source local-first assistant usable from chat apps, formerly Clawdbot. VERIFIED from [openclaw.ai](https://openclaw.ai/).
- Ollama integrates Hermes Agent with OpenClaw channels. Source: [PhantomByte](https://articles.phantom-byte.com/sovereign-ai-stack-2026-ollama-hermes-openclaw.html) (secondary source, treat with care).
